# うたとも（仮）β版

推し活SNS「ともはね」とつながる、**タップで曲を作るツール**です。楽譜が読めなくても、パネルを押すだけで1曲（15秒〜1分・ループ）ができます。案内役は 🐦 ことり（仮。まだ決まっていない）。

## 起動

Node.js 20 以上。外部パッケージは使っていません。

```sh
npm start        # http://localhost:4400
npm test
```

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉。**本番では必ず設定する** |
| `PORT` | ポート（ふだんは 4400） |

## できること（段階1：タップで曲・BGM モード）

- **雰囲気**（☀️明るい・🍬かわいい・🕶️かっこいい・☕おしゃれ・🌙しっとり・🎉お祝い）と**長さ**（15秒・30秒・60秒・ループ）をえらんで「🎲 おまかせ」→ 曲の設計図（イントロ→Aメロ→Bメロ→サビ→おわり）を自動で組み立てる
- **パネルをタップ**：🥁リズム・🎸ベース・🎹コード・🎶メロディ・✨キラキラ の5列 × 4つ。1列から1つだけ光る。再生中に押すと次の小節から変わる（DJ のようにループを重ねる）
- どのパネルも同じテンポ・同じ和音にそろうので、どれを押しても音がぶつからない（メロディは和音の音だけを使う）
- 部分の切れめに、ドラムのフィルが自動で入る
- テンポを変えられる（70〜150）
- 🎙️ 声のじゃまをしない：音を小さめ・メロディひかえめ（動画や配信の後ろに）
- 🔁 えらんだ部分だけくり返す
- ループは、余韻を頭にもどして、つなぎ目なしで流せる
- 💾 音を書き出す（WAV・44.1kHz・ステレオ・透かしなし）／📤 シェア（スマホのシェア画面）
- 📋 クレジットをコピー（「#ともはね #うたとも」）／📣 ともはねの広場で知らせる（下書きが入るだけ。送るかは本人が決める）
- ともはねでログインすると、**1人10曲まで**保存・上書き・消すができる。ログインしなくても作る・聞く・書き出すはできる

## しくみ

- 音はすべて `public/music.js` で計算して作る（録音した音源・外のサービス・AI は使わない）。ブラウザでもサーバーでも同じファイルを使う
  - `buildBgm(mood, length, { rng, quiet, tempo })`：雰囲気と長さから曲の設計図を作る
  - `renderBar(...)`：1小節ぶんの音（再生はこれを Web Audio で予約していく）
  - `renderSong(song)`：1曲の音（書き出し用）／`encodeWav(left, right, sampleRate)`
  - `checkSong(song)`：保存・読みこみの前に、決まった形かどうかを確かめる
- 保存するのは「曲の設計図」（雰囲気・テンポ・部分とパネル）だけ。音はいつでも同じように作りなおせる
- データはメモリの中だけ（β版。サーバーを止めると消える）
- ともはね に渡すもの・受けとるもの：受けとるのは「アプリ用の番号・表示名・年齢の区分」だけ。結果は返さない
